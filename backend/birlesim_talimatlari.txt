Merhaba,

Proje dosyalarını oluştururken bazı sınırlamalar nedeniyle tasks.py dosyası üç parçaya bölündü. Bu parçaları birleştirmek için aşağıdaki adımları izleyebilirsiniz:

1. rapor/tasks_part1.py, rapor/tasks_part2.py ve rapor/tasks_part3.py dosyalarını açın.

2. Bunları tek bir tasks.py dosyasında birleştirin:
   - tasks_part1.py'nin tüm içeriğini alın
   - tasks_part2.py içeriğini (import ifadeleri olmadan) tasks_part1.py'nin sonuna ekleyin
   - tasks_part3.py içeriğini (import ifadeleri olmadan) birleştirilmiş dosyanın sonuna ekleyin

3. Birleştirilmiş içeriği "C:\Users\fuchs\Desktop\Kapadokya_AI\backend\kapadokya_project\rapor\tasks.py" dosyasına kaydedin.

4. Aşağıdaki fonksiyonların varlığını kontrol edin:
   - generate_report
   - generate_isg_report_data
   - generate_productivity_report_data
   - generate_production_report_data
   - generate_general_report_data
   - generate_charts_config
   - generate_ai_analysis
   - generate_summary_analysis
   - generate_trend_analysis
   - detect_anomalies
   - generate_recommendations
   - check_scheduled_reports
   - calculate_date_range
   - calculate_next_run

Bu proje, YOLOv11 entegrasyonu için bir Django REST API arka uç sistemini içerir. Görüntü işleme ile İş Sağlığı ve Güvenliği (İSG), işçi verimliliği takibi ve ürün sayımı/kalite kontrolü gibi özellikleri içermektedir.

Projeyi çalıştırmak için:

1. Gerekli Python paketlerini yükleyin:
   ```
   pip install -r requirements.txt
   ```

2. Veritabanını oluşturun:
   ```
   cd backend
   python manage.py migrate
   ```

3. Bir admin kullanıcısı oluşturun:
   ```
   python manage.py createsuperuser
   ```

4. Geliştirme sunucusunu başlatın:
   ```
   python manage.py runserver
   ```

5. Background görevleri (Celery) için:
   ```
   celery -A kapadokya_project worker -l info
   ```

API dokümantasyonu şu adreslerden erişilebilir:
- http://localhost:8000/swagger/
- http://localhost:8000/redoc/

Not: Bu proje YOLOv11 modellerini kullanmaktadır. Model dosyalarınızı "backend/kapadokya_project/ai_models/yolov11_models/" dizinine yerleştirmeniz gerekir.
